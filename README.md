The RentalHub is a web-based platform developed to modernize and streamline the rental process between tenants and landlords. It offers an organized and transparent system for managing property listings, tenant interactions, and rental transactions. The project primarily serves as a centralized hub where tenants can browse available properties and book appointments to visit them, while landlords (who act as the admin) can manage property details and tenant records effectively.
Tenants can register, log in, and search properties using filters like location, price, and type. Once they find a suitable property, they can book an appointment to connect with the landlord. The admin receives and reviews all appointment requests and has the authority to accept or reject them. Users are notified about the status of their request, ensuring smooth communication and minimizing delays in the rental process.
After appointment approval, the admin can add the user as a tenant and create a rental agreement that includes important details such as rent amount, agreement period, and property information. These agreements are stored for future reference and legal clarity. The system supports complete management of tenant data, property availability, and rent history.
The Rent Payment Module allows the admin to record and track monthly payments from each tenant. It maintains the payment status for every month, highlighting pending and completed transactions. This helps landlords monitor cash flow and avoid missed payments. Additionally, the system provides clear history logs for each tenant’s payment and rental status.
Built using HTML, CSS, JavaScript, PHP, and MySQL, the platform ensures responsive design, secure user authentication, and reliable data storage. With real-time notifications and admin-controlled features, the website brings automation and ease to the rental process. Overall, the House Rental Website serves as a complete solution for small-scale rental management by combining user interaction with backend administrative control.
